## 5. 裏モード仕様

### 5.1 起動方法

デバッグビルド（`_DEBUG` マクロが定義されている場合）のみ、タイトル画面の右下に「DXLIBサンプル」ボタンを表示する。
選択すると裏モードメニューへ遷移し、「描画サンプル」「入力サンプル」のどちらかを選択する。

```cpp
// 表示条件の制御例
#ifdef _DEBUG
    // 「DXLIBサンプル」ボタンを描画
#endif
```

リリースビルドでは当該ボタンは描画されず、裏モードへの遷移手段は存在しない。

### 5.2 描画サンプル画面（SCR_DEBUG_DRAW）

DxLibの図形描画関数の出力を一覧表示する。

```
┌────────────────────────────────────────────────────────────┐
│  [← →] でページ切替    [ESC] で戻る                        │
├────────────────────────────────────────────────────────────┤
│                                                            │
│  DrawPixel          DrawLine         DrawBox               │
│       ●               ／              □                   │
│                                                            │
│  DrawCircle         DrawTriangle     DrawQuadrangle        │
│       ○               △              ◇                   │
│                                                            │
│  DrawFillBox        DrawFillCircle   DrawFillTriangle      │
│       ■               ●              ▲                   │
│                                                            │
│  （関数名を画像の下に表示する）                              │
└────────────────────────────────────────────────────────────┘
```

| ページ | 表示内容 |
|--------|----------|
| 1 | 基本図形（点・線・矩形・円・三角・四角形） |
| 2 | 塗りつぶし図形 |
| 3 | 文字列描画（DrawString / DrawFormatString） |
| 4 | 色・ブレンドモード（SetDrawBlendMode） |

### 5.3 入力サンプル画面（SCR_DEBUG_INPUT）

キーボードおよびコントローラーの入力状態をリアルタイムで表示する。

```
┌────────────────────────────────────────────────────────────┐
│  [ESC] で戻る                                              │
├──────────────────────────┬─────────────────────────────────┤
│    キーボード             │    コントローラー               │
│                          │                                 │
│  KEY_INPUT_UP    : ○    │  PAD_INPUT_UP    : ●           │
│  KEY_INPUT_DOWN  : ○    │  PAD_INPUT_DOWN  : ○           │
│  KEY_INPUT_LEFT  : ○    │  PAD_INPUT_LEFT  : ○           │
│  KEY_INPUT_RIGHT : ●    │  PAD_INPUT_RIGHT : ○           │
│  KEY_INPUT_Z     : ○    │  PAD_INPUT_1     : ○           │
│  KEY_INPUT_X     : ○    │  PAD_INPUT_2     : ○           │
│  KEY_INPUT_A     : ○    │  ...                            │
│  KEY_INPUT_D     : ○    │                                 │
│  KEY_INPUT_RETURN: ○    │  アナログスティック              │
│  KEY_INPUT_ESCAPE: ○    │  Left  X: 0.00  Y: 0.00        │
│  ...                    │  Right X: 0.00  Y: 0.00        │
│                          │                                 │
│  最後に押したキー:        │  最後に押したボタン:            │
│  KEY_INPUT_RIGHT         │  PAD_INPUT_UP                  │
└──────────────────────────┴─────────────────────────────────┘
```

- ●（塗りつぶし） = 押下中、○（白抜き） = 未入力
- CheckHitKey / GetJoypadInputState / GetJoypadAnalogInput を使用して取得
- コントローラー未接続時は「コントローラー未接続」と表示

## 6. メーターパネル仕様

### 5.1 タコメーター

- 表示範囲：0〜10,000 RPM
- 形式：アナログ円形（針が回転）
- レッドゾーン：8,000 RPM 以上

### 5.2 スピードメーター

- 表示範囲：0〜300 km/h
- 形式：アナログ円形（針が回転）

### 5.3 燃料計

- 表示範囲：E（空）〜 F（満タン）
- 形式：アナログ半円ゲージ（針）

### 5.4 水温計

- 表示範囲：C（低温）〜 H（高温）
- 形式：アナログ半円ゲージ（針）
- 高温警告：H 側に近づくと色が変化

### 5.5 デジタル表示

- 速度（km/h）
- エンジン回転数（RPM）
- ギア段数
- 表示形式：7セグ風フォント

## 6. レースロジック仕様

### 6.1 走行モデル（概要）

- プレイヤーの操作（アクセル）に応じてRPMが上昇する
- RPMと現在ギアに応じて速度が決まる
- 走行距離は速度の積分で計算する
- 400m到達でゴール

### 6.2 ギアチェンジ

- 手動変速（プレイヤーが任意のタイミングで操作）
- ギアアップするとRPMが下がり、速度帯が上がる

### 6.3 CPU対戦相手

- CPUは自動で最適なタイミングでギアチェンジする
- 難易度設定により速度・加速のパラメータを調整する（案）

## 7. 操作仕様

| 操作 | キー |
|------|------|
| 選択 / 決定 | Enter / Z キー |
| キャンセル / 戻る | X キー / ESC キー |

| 操作 | キー |
|------|------|
| アクセル | ↑ / Z キー |
| ギアアップ | A キー |
| ギアダウン | D キー |
| リタイア | ESC キー |
