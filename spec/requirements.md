# 要件定義

## 1. プロジェクト概要

### 1.1 プロジェクト名
car-gauge

### 1.2 目的
プログラミング練習を目的として、DxLib（DirectX）を用いたC++によるレースゲームを開発する。

### 1.3 概要
ゼロヨン（0-400m）をテーマにした横スクロール型レースゲーム。
画面レイアウトはゲーム画面とメーターパネルに分割する。

---

## 2. 機能要件

### 2.1 画面構成

| エリア | 画面比率 | 内容 |
|--------|----------|------|
| ゲーム画面 | 4/4 中 3/4 | 横スクロールの走行シーン |
| メーターパネル | 4/4 中 1/4 | 車両情報の表示 |

### 2.2 ゲーム画面

- 横スクロールによる走行シーンの描画
- 自車の操作（加速・ギアチェンジなど）
- 対戦相手（CPU）との競走
- ゴール（400m地点）の判定と勝敗表示

### 2.3 メーターパネル

以下のゲージ・メーターを表示する。

| メーター | 表示形式 | 内容 |
|----------|----------|------|
| スピードメーター | アナログ円形（針） | 車速（km/h） |
| タコメーター | アナログ円形（針） | エンジン回転数（RPM） |
| 燃料計 | アナログゲージ | 燃料残量 |
| 水温計 | アナログゲージ | エンジン水温 |
| デジタル数値表示 | 7セグ風フォント | 速度・RPM等の数値 |

### 2.4 マイガレージ画面

タイトル画面の次に表示されるハブ画面。以下の3つの操作を選択できる。

| 選択肢 | 内容 |
|--------|------|
| 車を買う | カーディーラー画面へ遷移し、新しい車を購入する |
| カスタマイズ | 所有車のパーツ交換・チューニングを行う |
| レース開始 | 現在選択中の車でゲーム画面へ遷移する |

### 2.5 カーディーラー画面

- 購入可能な車の一覧を表示する
- 各車の性能（最高速度・加速力など）と価格を確認できる
- 所持金と相談しながら購入できる
- 購入した車はガレージに追加される

### 2.6 カスタマイズ画面

- ガレージにある車を選択してパーツを変更できる
- カスタマイズカテゴリ（案）：

| カテゴリ | 内容例 |
|----------|--------|
| エンジン | 出力・レスポンス向上 |
| タイヤ | グリップ・加速性能変化 |
| ボディ | 重量・空気抵抗の変化 |
| 外装 | 見た目のカスタマイズ（カラー等） |

- カスタマイズにはゲーム内通貨（お金）を消費する
- 変更前後の性能差をプレビューで確認できる

### 2.7 オープニング画面

- ゲーム起動時にオープニング演出を表示する（実装済み：虹色アニメーション）
- タイトル文字の表示
- 開始操作によりタイトル画面へ遷移

## 3. 非機能要件

### 3.1 動作環境

| 項目 | 内容 |
|------|------|
| OS | Windows 10 / 11 |
| 言語 | C++ |
| ライブラリ | DxLib |
| 解像度 | 800 × 600（固定） |
| ウィンドウモード | ウィンドウ表示（リサイズ不可） |
| 文字コード | UTF-8 |

### 3.2 パフォーマンス

- メインループがスムーズに動作すること（処理落ちなし）
- メーターの針・ゲージはリアルタイムで更新されること

### 3.3 保守性

- ソースコードはヘッダーとソースに分離して管理する
- 型定義は `typedef.h` に集約する

---

## 4. 画面遷移

```
起動
 └─> オープニング画面（虹色アニメーション）
      └─> [任意キー] タイトル画面
           └─> [スタート] マイガレージ画面
                ├─> [車を買う] カーディーラー画面
                │    └─> [購入/キャンセル] マイガレージ画面へ戻る
                ├─> [カスタマイズ] カスタマイズ画面
                │    └─> [決定/キャンセル] マイガレージ画面へ戻る
                └─> [レース開始] ゲーム画面
                     └─> [ゴール/リタイア] リザルト画面
                          └─> [任意キー] マイガレージ画面へ戻る
```

## 5. 操作仕様（案）

| 操作 | キー |
|------|------|
| 加速 | ↑ / Z キー |
| ギアアップ | A キー |
| ギアダウン | D キー |
| ゲーム終了 | ESC キー |

## 6. 裏モード（DxLib描画サンプル）

### 6.1 概要

タイトル画面で特定のキー入力をすると、隠し機能として「DxLib描画サンプル画面」に遷移する。
DxLibの各機能を視覚的に確認することを目的とした開発者向け機能。

### 6.2 サンプル内容

| サンプル種別 | 内容 |
|--------------|------|
| 図形描画サンプル | 点・線・矩形・円・多角形など各描画関数の出力を一覧表示 |
| 入力検出サンプル | キーボード・コントローラーの各ボタンを押したとき、対応する関数名と入力状態をリアルタイムで表示 |

### 6.3 起動条件

- デバッグビルド時のみ、タイトル画面に「DXLIBサンプル」ボタンを表示する
- リリースビルドでは当該ボタンは表示されず、この画面へ遷移する手段は存在しない

---

## 7. 開発方針

- 学習・練習が主目的のため、機能を段階的に追加していく
- まずオープニング → タイトル → マイガレージ → ゲーム画面の遷移を実装し、その後メーターや走行ロジックを追加する
- カーディーラー・カスタマイズはゲームの骨格ができてから追加する
- DxLib描画サンプルは開発初期から並行して育てていく（機能を試す場として活用する）
- 外部リソース（画像・音声）は必要に応じて `resource/` フォルダに格納する
